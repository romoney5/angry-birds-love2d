Angry Birds on LÖVE

To download, head to https://github.com/romoney5/angry-birds-love2d/releases/latest , and download the first file.

Make sure you have LOVE installed. After that, you can simply double-click the .love file to play.

To test without the .love file, download the source code instead from that link, then unzip. Afterwards, go to C:\Program Files\LOVE\ and copy lovec.exe to the folder that you unzipped it in. Then, drag main.lua to lovec.exe (or love.exe).

If you are on Linux, you should be able to download a LOVE Flatpak, then go into the project folder, open a terminal, and run "love ."
